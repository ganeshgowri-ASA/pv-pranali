# 6.5 Sourcing — Component Procurement + INR Landed Cost

## Purpose
For each BoM v1 line item, identify dual sources, query distributors for
current pricing, and compute INR landed cost using karaveda MCP.

## Distributors

| Distributor | Region | Focus |
|-------------|--------|-------|
| Mouser Electronics | Global/IN | Electronic components |
| DigiKey | Global/IN | Electronic components |
| Element14 India | IN | Electronic components |
| Rajguru Electronics | IN | Passives, connectors |
| Mehta Associates | IN | Industrial electronics |
| Kaizen Components | IN | Power electronics |

## Steps
1. Load `docs/design/bom/p0_bom_v1.csv`.
2. For each line item:
   a. Search Mouser, DigiKey, Element14IN APIs (`dry_run=True`) for stock + price.
   b. Search Rajguru, Mehta, Kaizen via web for IN-local pricing.
   c. Identify primary and secondary source (dual-source requirement).
   d. Call karaveda MCP (`dry_run=True`) to compute INR landed cost
      (include customs duty, GST 18%, freight, insurance).
3. Flag items with single-source risk or lead time >12 weeks.
4. Output `docs/sourcing/p0_sourcing.csv`:
   ```csv
   item,mpn,primary_vendor,primary_price_inr,secondary_vendor,
   secondary_price_inr,landed_cost_inr,lead_time_weeks,dual_source,notes
   ```
5. Summarize total BoM landed cost (INR and USD at spot rate).

## Constraints
- `dry_run=True` for all API calls; no live orders placed.
- Store API credentials in `.env` (gitignored), never in code.
- Log all queries to Langfuse (`dry_run=True`).
