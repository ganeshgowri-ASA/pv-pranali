## `console/app.py` Plotly Tab
Add a "Gantt" tab to the existing Dash/Streamlit console app:
- Load `docs/gantt/gantt.yml`
- Render as `plotly.figure_factory.create_gantt` or `plotly.express.timeline`
- Color-code by phase:
  - Design (blue): M1–M3
  - Procurement (orange): M4–M5
  - Build (green): M6–M7
  - Integration (purple): M8
  - Commissioning (red): M9–M10
- Show today marker
- Export PNG button

## Steps
1. Generate `docs/gantt/gantt.yml` with all M1–M10 entries.
2. Check if `console/app.py` exists; if not, create stub Dash app.
3. Add Gantt tab to `console/app.py`.
4. Validate YAML parses correctly.
5. Output: `docs/gantt/gantt.yml`, updated `console/app.py`.
