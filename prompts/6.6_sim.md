# 6.6 Simulation Suite — ngspice / Octave / OpenFOAM / POV-Ray / EMC

## Purpose
Run simulation suite for P0 design validation. All runs default to `dry_run=True`.

## Simulations

### 6.6.1 Electrical — ngspice
- **Circuit**: I-V measurement board (`docs/design/schematics/p0_iv_board.spice`)
- **Analyses**: DC sweep, AC small-signal, transient noise
- **Key checks**:
  - Kelvin measurement error < 0.1% at Isc
  - ADC input range compliance
  - EMI filter attenuation @ 150 kHz–30 MHz
- **Output**: `docs/sim/ngspice/p0_iv_board_results.csv`

### 6.6.2 Control — Octave
- **Model**: PID temperature controller (platen)
- **Parameters**: Kp, Ki, Kd sweep; step response to ±10 °C disturbance
- **Key checks**:
  - Settling time < 5 min to ±0.5 °C
  - Overshoot < 2 °C
- **Output**: `docs/sim/octave/p0_temp_ctrl_results.csv`

### 6.6.3 Thermal/Optical — OpenFOAM (dry_run stub)
- **Domain**: Light tunnel air flow + thermal uniformity
- **Mesh**: structured hex, 1 M cells (stub)
- **Key checks**:
  - Air temperature uniformity ±2 °C over test plane
  - Irradiance spatial non-uniformity < 2%
- **Output**: `docs/sim/openfoam/p0_thermal_stub.md`

### 6.6.4 Optical — POV-Ray (dry_run stub)
- **Scene**: MH lamp / LED array + integrating tunnel
- **Key checks**:
  - Spatial uniformity map over 2000×1100 mm plane
  - Hot-spot identification
- **Output**: `docs/sim/povray/p0_optical_stub.pov`

### 6.6.5 EMC Pre-compliance
- **Method**: Radiated emissions estimate per CISPR 11 / IEC 61326-1
- **Tools**: OpenEMS or analytical model
- **Key checks**:
  - Class B limits at 10 m
- **Output**: `docs/sim/emc/p0_emc_precompliance.md`

## Steps
1. Check for ngspice, octave, openfoam, povray availability.
2. If `dry_run=True`: write stub output files with parameter placeholders.
3. If `dry_run=False`: run actual simulations and capture results.
4. Write summary report `docs/sim/p0_sim_summary.md`.

## Constraints
- `dry_run=True` default.
- OpenFOAM and POV-Ray runs are stubbed until HPC resources available.
