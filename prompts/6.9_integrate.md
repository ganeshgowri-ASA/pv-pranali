# 6.9 System Integration — IEC 60204-1 / IEC 60529 / IS 13947

## Purpose
Verify P0 system integration against machine safety and enclosure standards.

## Standards

| Standard | Scope | Key Requirements for P0 |
|----------|-------|------------------------|
| IEC 60204-1:2016 | Electrical equipment of machines | Panel wiring, earthing, labelling, emergency stop |
| IEC 60529:2013 | Degrees of protection (IP) | IP54 minimum for test area |
| IS 13947 (Parts 1–5) | Low-voltage switchgear | Contactor, MCB, RCD ratings for Indian grid |

## Integration Checklist

### IEC 60204-1
- [ ] Main isolator: lockable, accessible from outside enclosure
- [ ] Emergency stop: IEC 60947-5-5, Category 0 or 1, mushroom head red/yellow
- [ ] Earth continuity: <0.1 Ω main earth to all exposed conductive parts
- [ ] Cable routing: power/signal separation ≥50 mm or screened
- [ ] Labelling: all terminals, wires, devices per IEC 60204-1 §13
- [ ] Overcurrent protection: each circuit individually protected
- [ ] Functional testing: operational sequence as per design

### IEC 60529
- [ ] Enclosure IP rating: IP54 (dust protected, splash proof)
- [ ] Cable glands: IP-rated, correctly sized
- [ ] Door seals: continuous, undamaged

### IS 13947 (Indian switchgear standards)
- [ ] MCBs: IS 13947-2 rated for 415 V AC, 50 Hz
- [ ] Contactors: IS 13947-4-1, AC-3 duty
- [ ] Earth leakage: RCCB per IS 12640 (30 mA for personnel protection)

## Steps
1. Review design artefacts from 6.4 against each checklist item.
2. Flag non-conformances as issues in `docs/integration/p0_integration_issues.md`.
3. Sign off checklist to `docs/integration/p0_integration_checklist.csv`.
4. Generate integration test procedures `docs/integration/p0_integration_test.md`.

## Constraints
- `dry_run=True` for any automated checks.
