# 6.1 URS Ingest — XLSX → Markdown

## Purpose
Parse the RIL URS spreadsheet (`docs/urs/source/*.xlsx`) and emit a structured
markdown document at `docs/urs/p0_steady_state_simulator.md`.

## Inputs
- `docs/urs/source/<urs_file>.xlsx` — confidential, gitignored
- Customer: Reliance Industries Ltd, Module R&D Laboratory
- URS reference: iRIL-MxML-FRM-GE-003-Rev00

## Steps
1. Locate the latest `*.xlsx` in `docs/urs/source/`.
2. Parse all sheets; identify requirement rows by presence of a Req-ID column.
3. Map each requirement to one of the canonical sections:
   - Performance, Safety, Utility, Warranty, KPI, Calibration, Shipping, Supplier
4. For each requirement emit:
   ```
   ### <Req-ID> — <Short Title>
   **Section**: <section>
   **Priority**: <Must/Should/May>
   **Text**: <verbatim requirement text>
   **Acceptance criterion**: <criterion or TBD>
   **Linked standard**: <standard clause or —>
   ```
5. Append a summary table: Req-ID | Section | Priority | Status (Open/Closed).
6. Write output to `docs/urs/p0_steady_state_simulator.md` (prepend CONFIDENTIAL header).
7. Do NOT commit the source XLSX.

## Output
`docs/urs/p0_steady_state_simulator.md` — updated structured URS.

## Constraints
- `dry_run=True` unless overridden.
- Do not expose customer-confidential data in logs.
