## CSV Schema
```csv
standard,clause,clause_title,design_element,test_procedure,responsible,status
```

## Steps
1. For each standard above enumerate applicable clauses for P0.
2. Map clause → design element (e.g., "optical uniformity fixture", "4-wire I-V board").
3. Map clause → test procedure ID (e.g., "TP-OPT-001", "TP-IV-001").
4. Assign responsible (Design / Test / Supplier / Third-party lab).
5. Set status = Open initially.
6. Write `docs/compliance/p0_matrix.csv`.
7. Summarize coverage gaps in `docs/compliance/p0_gaps.md`.
