# 6.10 Commissioning — IQ/OQ/PQ + ISO/IEC 17025 + IEC 62304

## Purpose
Execute and document commissioning qualification for P0:
- IQ: Installation Qualification
- OQ: Operational Qualification
- PQ: Performance Qualification (including ISO/IEC 17025 calibration)

## IQ — Installation Qualification

### Checks
- [ ] Physical installation per approved drawings
- [ ] Utilities connected (3-phase power, cooling water/air, compressed air if req.)
- [ ] Environmental conditions: temperature 20±2 °C, humidity <60% RH
- [ ] Safety systems functional (E-stop, interlocks, alarms)
- [ ] Earth continuity verified
- [ ] IEC 60204-1 checklist signed off (from 6.9)

### Documents
- `docs/commissioning/iq/p0_iq_checklist.csv`
- `docs/commissioning/iq/p0_iq_report.md`

## OQ — Operational Qualification

### Checks
- [ ] Irradiance range: 700–1300 W/m² achievable, stable ±2%
- [ ] Spatial non-uniformity: ≤2% over test plane (IEC 60904-9:2020 Class A+)
- [ ] Temporal instability: ≤2% over measurement period
- [ ] Spectral match: Class A+ per IEC 60904-9:2020
- [ ] Temperature control: 20–75 °C, stability ±0.5 °C
- [ ] I-V measurement: linearity, repeatability per IEC 60904-1
- [ ] 4-wire Kelvin: contact resistance <0.1 Ω

### Documents
- `docs/commissioning/oq/p0_oq_protocol.md`
- `docs/commissioning/oq/p0_oq_results.csv`

## PQ — Performance Qualification (ISO/IEC 17025)

### Calibration Chain
- Reference solar cell: ISO 9060 Class A, calibrated by accredited lab (NABL/PTB)
- Pyranometer: ISO 9060 Class A secondary standard
- Pt-100: IEC 60751 Class AA, calibrated to NABL reference
- Multimeter (IV measurement): calibrated to national standards
- Uncertainty budget: per VIM JCGM 200:2012

### Measurement Uncertainty Targets
| Parameter | Target Uncertainty (k=2) |
|-----------|-------------------------|
| Irradiance | ±2% |
| Temperature | ±0.5 °C |
| Current (Isc) | ±0.5% |
| Voltage (Voc) | ±0.3% |
| Power (Pmax) | ±1.5% |

### Documents
- `docs/commissioning/pq/p0_uncertainty_budget.xlsx` (stub)
- `docs/commissioning/pq/p0_calibration_record.csv`
- `docs/commissioning/pq/p0_pq_report.md`

## IEC 62304 Applicability
P0 embedded firmware (IV sweep controller, PID loop) shall be documented per
IEC 62304 safety class B:
- Software requirements specification
- Software architecture
- Unit/integration test records
- `docs/commissioning/sw/p0_sw_lifecycle.md`
