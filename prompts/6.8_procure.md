# 6.8 Procurement — Purchase Orders + Incoming Inspection

## Purpose
Issue purchase orders for approved BoM items and define incoming inspection
criteria per IS 1664, IPC-A-610, and ASTM E2935.

## Process

### 8.1 PO Generation
1. Load `docs/sourcing/p0_sourcing.csv` (approved dual-source BoM).
2. For each line item marked `approved=True`:
   - Generate PO with: PO number, vendor, MPN, quantity, unit price INR,
     delivery address, required-by date, special instructions.
   - Format: `docs/procurement/po/PO-<YYYYMMDD>-<seq>.pdf` (stub).
3. Log PO issuance to `docs/procurement/po_log.csv`.

### 8.2 Incoming Inspection Criteria

| Category | Standard | Key Checks |
|----------|----------|------------|
| PCBs / SMD assemblies | IPC-A-610 Class 2 | Solder quality, component placement |
| Structural/mechanical | IS 1664 | Dimensional, surface finish |
| Optical coatings | ASTM E2935 | Reflectance measurement |
| Electrical components | Vendor CoC + IEC 61010-1 | Ratings, markings |
| Sensors (RTD, TC) | IEC 60751, IEC 60584-1 | Calibration certificate |
| Reference cell | ISO 9060 Class A | Calibration cert from accredited lab |

### 8.3 Inspection Records
- Template: `docs/procurement/inspection/incoming_inspection_template.csv`
- Fields: PO-Ref, Item, Qty-received, Qty-accepted, Qty-rejected, Inspector, Date, Notes

## Steps
1. Generate PO stubs for all `approved=True` BoM items (`dry_run=True`).
2. Write inspection criteria to `docs/procurement/inspection_criteria.md`.
3. Create incoming inspection template CSV.
4. Output PO log.

## Constraints
- `dry_run=True` → stubs only, no live orders.
- `live=False` default (parameter alias for dry_run).
- Store vendor credentials in `.env`.
