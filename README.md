# PV-Pranali

A self-driving multi-agent system that converts a single line of engineering intent into a
customer-ready proposal — BoM, CAD, PCB, SLD, pitch deck, landing page, and LinkedIn campaign —
by orchestrating 30+ ganeshgowri-ASA repos via MCP, running on Claude Code + MiMo in WSL/tmux.

## Docs

- [PRD.md](PRD.md) — Vision, goals, architecture, and risk register
- [docs/SESSIONS.md](docs/SESSIONS.md) — 24 bite-sized sessions across 5 phases

## Quick Start

```bash
cp .env.example .env    # fill in API keys
bash infra/launch.sh    # start tmux session pp
```
